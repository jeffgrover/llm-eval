# Office Building Simulation — One-Shot Prompt

Use the agentic coding tools available to you to write files that implement
an animated 3D simulation of a multi-floor office building and its inhabitants
running entirely in the browser with no build process.
The page must work when opened directly from a `file://` URL: use classic
scripts, not ES modules, imports, import maps, or `fetch()` to load code.

Make the indoor and outdoor environments beautiful and realistic, and
make the office interactions, elevator and worker behavior realistic
and high-fidelity representations of real-world office dynamics.
