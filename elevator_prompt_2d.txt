Build a small browser-based 2D elevator simulation from scratch. The current directory is an empty workspace: create the files you need here. Work only in this directory; do not use `find` or search outside it.

- Use plain HTML canvas and JavaScript to show a five-floor building and elevator.
- Start with four passengers on different floors, leaving one floor empty.
- Repeatedly choose a random passenger and take them by elevator to the empty floor; their old floor becomes empty.
- Create the simulation before running the provided checks: `node ../../static_check.js .` and `node ../../runtime_check.js .`.

Keep the implementation simple. The task is a 2D HTML/JavaScript simulation that repeatedly moves a random passenger to the currently empty floor.
